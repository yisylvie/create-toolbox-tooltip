# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.0.4+1.21.1] — 2026-04-04

### Added

- Support for Minecraft v1.21.1.
- Ability to toggle on/off Create&rsquo;s default tooltip for toolboxes.

### Fixed

- Lock keybinds now work and display properly for empty toolboxes.

### Changed

- Shulker Box Tooltip dependency to v5.1.9+1.21.1.

### Removed

- Architectury dependency.
- Fabric, Quilt, and Forge support.

## [1.0.4+1.20.1] — 2026-04-04

### Added

- Ability to toggle on/off Create&rsquo;s default tooltip for toolboxes.

### Fixed

- Lock keybinds now work and display properly for empty toolboxes.

## [1.0.3+1.20.1] — 2026-03-06

### Added

- Option in Shulker Box Tooltip&rsquo;s mod config to disable previews for other container types.

### Fixed

- Bug in which mixins were not added thus disabling many features relating to empty item stacks.
- Edge case in which toolboxes with two stacks >= 1000 had overlapping tooltip text on compact mode.

### Changed

- Switched changelog to [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) format.

## [1.0.2+1.20.1] — 2026-02-16

### Added

- Now works on Forge and NeoForge.

### Changed

- Update to Architectury for multi-loader support.

## [1.0.1+1.20.1] — 2025-03-03

### Added

- Now works with every version of Create for mc1.20.1.

## [1.0.0+1.20.1] — 2025-02-24

- Initial Release.
